# Password Generator and Management

## About the Project
This project is a Java-based Password Generator and Management application designed to generate strong passwords and manage password information.

## Features
- Generates random passwords.
- Includes uppercase and lowercase letters, numbers, and special characters.
- Supports password management.
- Uses Java and Hibernate.
- Uses MySQL for database storage.

## Technologies Used
- Java
- Maven
- Hibernate
- MySQL
- HTML

## How to Run
1. Clone or download this repository.
2. Import the project into Eclipse as an existing Maven project.
3. Configure the MySQL database connection in `hibernate.cfg.xml`.
4. Run `PasswordServer.java` to start the web server.
5. Open the URL printed in the Eclipse Console.
